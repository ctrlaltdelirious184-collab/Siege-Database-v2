Welcome to the Siege Database Beta! This app is designed to help you track 
your siege performance and use AI-driven insights to counter defenses.

QUICK START (Installation)
──────────────────────────
1. INSTALL THE PLUGIN:
   - Open Summoners War Exporter (SWEX).
   - Go to the "Plugins" folder.
   - Copy the 'SiegeDatabase' folder from this package into your SWEX plugins directory.
   - Restart SWEX. You should see "[v2.8] Monitoring Siege" in the logs.

2. RUN THE APP:
   - Double-click 'SiegeDatabase.exe' in the 'dist' folder.
   - No installation or Python required!

3. CONFIGURE YOUR IGN:
   - On first launch, enter your exact In-Game Name (IGN).
   - This allows the app to find YOUR battles in the real-time logs.


KEY FEATURES
────────────
📊 Dashboard     — Real-time stats, win rates, and performance trends.
⚔  Defenses      — Filter history by guild or team composition.
🤖 AI Advisor    — Ask the AI for the best counters based on your data.
📥 Auto-Ingest   — Battles are automatically recorded while you play.


TIPS FOR TESTERS
────────────────
• Keep SWEX running while you siege for automatic recording.
• If you need to backfill old data, use the "Import Logs" button in the menu.
• The AI Advisor works best after you've recorded at least 20-30 battles.
• Data is saved in 'siege.db' — back this file up if you want to keep your history!
